MultiUserFullBody is a Unity-based research prototype for multi-user, full-body immersive interaction. The project is developed as part of Mason Prather's Graduate Research Assistant work at Kennesaw State University under the supervision of Dr. Lei Zhang.

The project originally explored networked embodiment, avatar synchronization, and shared VR interaction workflows. During the Spring 2026 semester, its scope shifted toward media sharing, with a greater focus on phone-based upload workflows that enable users to share photos and other media within a social VR space.

This repository contains the Unity project source, scenes, scripts, and supporting assets for that research and development work. Dependencies and implementation details continue to evolve as deprecated packages are removed and the architecture is refined.
